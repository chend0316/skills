# 交互式 HTML 输出

默认使用本参考生成交互式 HTML；仅在用户明确要求纯文本、不生成 HTML 或其它格式时，遵循其格式要求。先按对应地图规则完成源码核查与原始地图，再将同一份数据渲染为可本地打开的独立 HTML 文件，内嵌 CSS、JavaScript 和地图数据，不依赖在线 CDN。不需要创建或部署网站，也不修改被分析工程；将产物写入合适的输出目录并交付可点击文件链接。

源码地图页面使用 [生成脚本](../scripts/generate_dependency_html.py)；输入格式和运行命令见 [HTML 生成技巧](html-generation.md)。具体实现参考同一文档：数据快照、安全内嵌、路径渲染、折叠算法、复制与验证。

## 页面与数据

- 源码地图网页提供“原始地图”“复制原始地图”“源码地图”三个视图/操作选项，并在顶部通过“依赖类型”提供全局筛选。不要再添加入口依赖树、三态循环、下拉框、全部展开/收起等控件，除非用户要求。其他地图类型沿用其对应视图名称。
- 初始视图完整展开；原始文本不带 `[-]`、`[+]`，不受交互状态裁剪。原始地图和交互地图遵循相同的路径行语义：目录结构每个文件夹一行，文件依赖每个完整相对路径一行。
- 支持当前请求涉及的地图类型，不强制生成其它地图。运行地图保留模块、直接调用/绑定/回调边、条件分支、执行顺序与 UI 标注；目录图保留真实包含关系；源码地图保留依赖方向及目录聚合语义。不要为方便折叠将顺序调用误当成层层调用。
- 原始图与视图状态分开保存。节点具有稳定身份；同一目标的多次展示使用独立展示身份并关联原始节点。真实包含关系与有向依赖边分别存储，目录聚合节点不伪装成真实依赖边。
- 源码地图展示资源使用点。顶部“资源类型”与“依赖类型”并列，按源码使用点计数并独立筛选；顶部的资源筛选只影响资源引用，依赖筛选只影响非资源引用。原始地图和复制内容保留完整使用点及源码位置。
- 依赖边保留源、目标、类型、证据、条件与解析状态，并保存分析根目录、成员关系及覆盖范围。页面显示范围说明和证据缺口；可以在详情区查看来源与证据。
- 切换状态只重新计算视图，不能删除原始边或改变方向。文本和源码片段按文本安全渲染；序列化内嵌数据时正确转义，避免源码内容破坏 HTML 或脚本。
- 展开控件支持键盘操作并提供可访问名称与 `aria-expanded` 状态；无子项节点不显示无效控件。循环边明确标注并终止该分支递归。

## 各类地图的收起语义

运行地图收起节点时隐藏其展示子树，保留节点本身，在节点尾部显示一句下游功能总结；展开后恢复子树并隐藏这句总结。总结说明该子树的业务作用、关键分支及结果，不能只写“包含 N 个节点”，也不能补入未经源码证实的行为。总结单独保存在展示数据中，不替代原始节点、边或已有注释，不写入原始地图及其复制文本。叶子节点不显示折叠按钮或收起总结。不套用编译依赖的跨目录汇总规则。

目录结构图收起目录时隐藏全部后代，不在目录下展示外部引用。

### 编译依赖节点与分类筛选

- **目录**：单击名称或箭头只在展开/折叠之间切换。展开时没有右侧“展开”文案；折叠时隐藏所有内部文件，右侧显示非零类别计数，如 `系统API(1) 图标(2)`，不显示“0”类目。每个分类按钮独立控制该目录对应的直接外部引用：高亮表示显示，置灰表示隐藏。初次折叠默认各类隐藏，重新展开/折叠保留原选择。
- **文件**：始终展开，无折叠按钮和 `aria-expanded`。右侧使用与目录相同的分类计数按钮，筛选该文件的直接引用，默认全部显示；点击文件名查看证据，不改变结构。包、未解析资源或无出向依赖的叶子不显示无效筛选按钮。
- **全局筛选**：默认全部显示，作用于交互图中所有引用分类，包括展开文件的依赖和折叠目录的外部汇总。全局隐藏优先于节点选择：隐藏相应的引用和节点按钮，并保留原本选择；全局恢复后恢复节点偏好。筛选只隐藏引用，不删除真实目录/文件条目。
- 每个分类数量是**原始快照中的规范化目标去重数**，不随当前筛选减少，也不按显示路径或调用次数统计；同一 JSON 多个资源 key 算一个文件目标，所有来源/符号仍可在证据中查到。计数标签保留，便于重新开启。文件偏好按规范化文件身份保存，目录偏好按真实目录身份保存，展示实例各自保留父子关系。
- **可观测性**：与依赖和资源共用目录树分类按钮的显示和状态规则。文件默认展示自身的埋点、日志，折叠目录可按类展示目录内的使用点，默认收起。按源码位置计数，全局关闭时隐藏对应的局部按钮及明细。
- 原始地图、复制内容及基础统计始终基于完整快照，不受全局、文件、目录筛选或折叠影响。分类标题是展示分组，不是目录或额外编译边。目录可键盘展开，分类按钮提供 `aria-pressed`，有清晰的焦点样式。

### 目录汇总与路径

目录 D 的外部引用始终从**全部原始边**计算：`source ∈ D` 且 `target ∉ D`，包括未从入口可达或当前不可见的文件；部分扫描必须说明汇总范围。隐藏 D 的文件、子目录和内部相互依赖，对外部目标按类别和规范化身份去重，保留全部来源及状态。嵌套折叠不能从当前 DOM 汇总，不能用字符串前缀把 `module_a2` 归进 `module_a`。未解析候选、条件不明的引用继续显示其状态。

已定位的资源文件按实际规范化路径判断目录成员关系；不能因类别是资源就永远当作目录外目标。没有确定位置的资源符号保留为候选边界，详见 [资源引用与分类](resources-and-categories.md)。

文件下的依赖路径相对于直接引用文件；折叠目录下的外部依赖路径相对于该目录。每条依赖路径单独一行，不能把 `../` 或 `src/main/ets/` 拆成可折叠目录。目录结构/入口定位仍逐级显示文件夹。

**整目录模式**：用真实成员构建目录树，逐个文件列出直接依赖，包括入口不可达文件。目录内重复引用是证据终点，完整依赖在目标自身条目查看，避免重复递归膨胀；不要将所有成员伪造为入口依赖。**入口模式**：递归展开已声明的入口子图，沿祖先链检测循环并保留循环边，不用全局 visited 丢弃其他分支的引用。

例如折叠 `module_a/panels/` 时，启用源码分类应显示 `module_a/common_ui/Text.ets` 与 `module_b/common_ui/Button.ets`；折叠 `module_a/` 时，其内部 `Text.ets` 隐藏，只留下 `module_b` 的目标。重新展开恢复全部结构和原先筛选状态。

## 运行地图的源码超链接

- 叶子与非叶子节点的名称均支持源码跳转，目标精确到已核实的代码文件和一基行号。节点名称用于跳转，独立的加减按钮用于展开/收起；点击链接不能同时改变折叠状态。
- 普通调用节点链接到**当前调用路径中调用该方法的语句**，而不是被调用方法的定义。同一个方法出现在不同路径时，按展示实例分别记录调用位置，不能统一链接到方法声明或全仓首个引用。例如 `LocalCheckDialogUtils.isMMMeeting` 应链接到调用方内的 `LocalCheckDialogUtils.isMMMeeting()` 那一行。
- 没有图内调用方的入口节点可以链接到入口定义；回调节点链接到对应回调体或注册处；实现绑定节点链接到已有绑定证据；条件分支链接到对应判断；说明性终点链接到对应调用或返回语句。分组条件覆盖多个判断时，在详情中说明定位范围。定位类型应能从提示或详情中辨认，不把定义、绑定或条件位置标成普通调用处。
- 缺乏可核查源码位置时，标明缺口，不编造文件、行号或以相近定义冒充调用证据。源码链接定位与地图结构分开维护；补链核查不等于刷新整张调用关系快照。
- 沿用用户已指定的编辑器。使用 VS Code 时，链接格式为 `vscode://file/absolute/path:line`，路径正确做 URI 编码；悬停提示显示文件、行号和源码片段。不要仅用不能定位行号的文件链接冒充精确跳转。编辑器尚未确定且影响交付时，再询问用户。

## 交付前验证

在可用浏览器环境中打开生成的 HTML，确认实际渲染、目录展开与收起、文件/目录分类按钮、全局筛选、视图切换和原始文本复制；检查控制台错误。源码地图核查上述两个折叠边界与重新展开，并检查多来源去重、循环、别名和未解析边是否完整保留。根据实际数据验证适用场景，不必为每份产物添加测试工程。没有可用浏览器时执行可行的静态检查，并明确说明未完成交互验证，不宣称已经验证。

运行地图还需检查：收起时只显示对应子树总结，展开后总结消失且子节点完整恢复；叶子与非叶子节点均有准确的源码目标；普通运行地图接命中本路径中的调用表达式；名称链接与折叠按钮互不触发；视图切换与复制保留完整原始地图。核查目标文件存在、行号有效且源码片段匹配。脚本检查、浏览器交互和实际编辑器跳转分别报告验证范围；未实际打开编辑器时不声称跳转已验证。浏览器策略拒绝本地文件或编辑器协议时，不绕过限制。

核查文件节点即使带有子依赖也没有折叠控件；全局隐藏对文件和目录汇总均生效，恢复后保留本地偏好，零计数不显示；同目录、子目录、跨目录和包入口转导出均每条依赖一行，没有连续 `../` 或 `src/main/ets/` 形成的伪目录链。仅调整展示规则时沿用原分析数据快照；需要刷新源码分析时明确区分新旧快照，不得静默混合旧引用与新源码证据。

聊天附件预览可能不执行 JavaScript。交付时如实说明需要下载后用浏览器打开；不要把静态兜底图当作已实现交互，也不因预览限制擅自部署网站或绕过浏览器策略。
